# Prediksi Harga HP (Cellphone Price Range)

Project Machine Learning untuk memprediksi kategori harga HP berdasarkan spesifikasi perangkat keras (RAM, baterai, kamera, dll).
1. Fitur
- Model Klasifikasi menggunakan **Gradient Boosting Classifier**.
- Web API dan Form UI menggunakan **Flask**.
- Preprocessing menggunakan `StandardScaler`.
